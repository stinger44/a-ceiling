# Мост (Cascade Relay) для обхода «белых списков» и ТСПУ

Обычные VPN протоколы (даже современные, такие как VLESS) могут подвергаться блокировкам по пулам IP-адресов или паттернам трафика. Для гарантии бесперебойной работы мы используем архитектуру «Каскад», пропускающую трафик через доверенные внутрироссийские узлы.

## 🏗 Архитектура

1. **Node A (Клиент)**: Ваше устройство (телефон, ПК) на территории РФ.
2. **Node B (Мост / Relay)**: VPS внутри РФ (Yandex Cloud, EdgeCenter, VK Cloud). Трафик направляется сюда под видом обращений к внутренним ресурсам (маскировка).
3. **Node C (Exit Node)**: Ваш зарубежный VPS с Marzban панелью.

### Как работает маскировка (SNI Spoofing)
Для прохождения жестких фильтров ("белые списки") на Node B мы имитируем обращения к ресурсам, блокировка которых приведет к поломке интернета в стране. В нашем решении используются домены мобильных операторов:
- `mts.ru`
- `megafon.ru`
- `vk.com` / `gosuslugi.ru`

Провайдер видит обычный HTTPS трафик до Яндекса или МТС (на российский IP-адрес) и пропускает его без подозрений. Node B принимает этот трафик, снимает маскировку и перенаправляет полностью зашифрованный поток на Node C (За рубеж).

## 🚀 Развертывание 모ста (Node B) в Yandex Cloud

В проекте уже предусмотрен автоматический скрипт для быстрого поднятия Node B.

> [!WARNING]
> Для работы скрипта у вас должны быть установлены утилита `yc` (Yandex Cloud CLI) и авторизован профиль (`yc init`).

### 1. Подготовка `.env`

Убедитесь, что в файле `.env` в корневой папке указаны данные от зарубежного VPS (Node C):
- `VPS_IP`
- `VLESS_UUID`
- `REALITY_PUBLIC_KEY`
- `REALITY_SHORT_ID`
- `YC_FOLDER_ID` — ID вашего каталога в Yandex Cloud.

Добавьте туда же переменную для выбранного SNI маскировки (по умолчанию он будет использовать `mts.ru`, если не указано иное):
```bash
RELAY_SNI="megafon.ru" # Или mts.ru, vk.com
```

### 2. Запуск деплоя

```bash
bash relay/deploy-relay-yc.sh
```

Скрипт автоматически:
1. Создаст прерываемую (preemptible - для экономии бюджета) виртуальную машину в Yandex Cloud.
2. Развернет на ней Xray-core.
3. Пропишет маршруты: Входящий со SNI оператора -> Исходящий до зарубежного VPS.
4. Выдаст в консоль готовую **VLESS-ссылку (Layer 2)**.

### 3. Подключение в клиенте
Скопируйте ссылку VLESS, которую выдал скрипт, и добавьте в клиент (v2rayNG, Nekobox или Hiddify). Трафик пойдет через каскад.

## 🔀 Раздельное туннелирование (Split Tunneling)

> [!TIP]
> **Почему это важно:** Каскад удваивает расходы трафика (входящий в РФ-сервер и исходящий за рубеж). Кроме того, ТСПУ могут заблокировать российский сервер, если увидят аномальный объем трафика от одного пользователя. Раздельное туннелирование позволяет пускать в каскад **только заблокированные** сайты (Instagram, Twitter), а Youtube или Госуслуги оставлять без VPN.

### Настройка в v2rayNG (Android)
1. Откройте v2rayNG -> **Настройки** (Settings).
2. Выберите раздел **Настройки маршрутизации** (Routing Settings).
3. Включите **Пользовательские правила (Custom rules)**.
4. Режим по умолчанию укажите как **Bypass** (пропускать напрямую) или **Proxy** — в зависимости от того, как вам удобнее.
5. Зайдите в **Правила маршрутизации (Routing rules)**.

**Для пуска только заблокированного в VPN:**
- Нажмите «+» для создания правила.
- В поле `domain` добавьте ключевые слова:
  ```text
  domain:instagram.com, domain:twitter.com, domain:facebook.com, geosite:netflix
  ```
- Категория выхода (OutboundTag): `proxy`.

**Для исключения российских сайтов из VPN:**
Если вы по умолчанию используете VPN для всего, добавьте правило исключения:
- В поле `domain`: `geosite:ru`, `domain:yandex.ru`, `domain:vk.com`.
- Категория выхода (OutboundTag): `direct`.

### Настройка в Hiddify
Hiddify по умолчанию использует встроенные правила маршрутизации.
1. Перейдите в **Settings -> Routing**.
2. Установите режим маршрутизации на **Block QUIC** или настройте кастомные группы.
3. В Hiddify Next можно зайти в **Rules** и прописать маршруты: `geosite:ru` и `geoip:ru` с правилом **Direct**. Все остальные сайты пойдут по правилу **Proxy**.

### Настройка в Nekobox (Windows)
1. Выберите **Settings -> Routing**.
2. В секции **Direct Domain** добавьте: `geosite:ru`, `domain:ru`.
3. В секции **Direct IP** добавьте: `geoip:ru`.
Это направит весь внутрироссийский трафик мимо туннеля напрямую от вашего провайдера, снижая нагрузку на РФ-облако (Node B).
