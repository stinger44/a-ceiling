# Caskade VPN Registration Bot

This repository contains the Telegram bot used for registering users and managing subscriptions in the Caskade VPN network via the RemnaWave API.

## Features
- Automated user registration in the RemnaWave panel.
- Dynamic subscription link generation.
- Status checks for existing users.

## Structure
- `registration_bot/`: Python bot source code (`aiogram` + `sqlmodel`).
